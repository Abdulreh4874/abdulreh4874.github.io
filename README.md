# prageethbanuka.github.io

Personal site of Banuka Rajapaksha: computer engineer and designer. *Coffee runs through my circuits.*

Static HTML, CSS and JavaScript. No build step. Hosted free on GitHub Pages.

| Page | What's there |
|---|---|
| `index.html` | Oscilloscope hero and the tuner |
| `engineering.html` | Six live project demos and IEEEXtreme |
| `design.html` | Poster wall, index and X-ray |
| `experience.html` | WSO2, timeline, leadership, education |
| `offhours.html` | Red-light mode: live sky, astrophotography, drum machine |

- `assets/site.css`, `assets/site.js`: shared design tokens, springs, nav and footer
- `assets/moments.js`: automatic date and time features (preview with `#moment-<id>`)
- `assets/secret.js`: an encrypted note. `tools/seal.html` re-seals it locally

Run locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
