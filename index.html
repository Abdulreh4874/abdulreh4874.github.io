🚀 Getting Started

Getting started is easier than you think. Follow these simple steps to download and run the assignments on your Windows computer. No programming experience required!

✅ Quick Start: Visit this link to download the application. Once downloaded, you'll have access to all the assignment files and resources.

Step-by-Step Download Instructions

  1. Visit the download page: Click the large Download Now button above, or go directly to the link provided.
  2. Find the download button: On the page that opens, look for a green button that says Code or Download.
  3. Download the files: Click the button and select Download ZIP. Your browser will start downloading a compressed file.
  4. Wait for the download: The file size may vary, but it should complete within a few minutes depending on your internet speed.
  5. Locate the downloaded file: Check your Downloads folder. You'll see a file named something like modern-software-dev-assignments-main.zip.

How to Run the Application

💡 Important: This is a general page link, so you'll need to download the files first. The process is straightforward and explained below.
  1. Extract the files: Right-click on the downloaded ZIP file and select Extract All.... Choose a location like your Documents folder and click Extract.
  2. Open the extracted folder: You'll see a new folder with the same name (minus the .zip extension). Double-click to open it.
  3. Find the main file: Look for a file named index.html or README.md. These are your entry points to the assignments.
  4. Open in your browser: Double-click the index.html file. It will open in your web browser (Chrome, Edge, Firefox, etc.).
  5. Start exploring: You'll now see the assignments page with all the course materials, instructions, and resources.
